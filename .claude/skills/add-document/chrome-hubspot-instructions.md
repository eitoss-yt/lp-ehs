# HubSpot：「{{資料名}}」の資料DLフォームとお礼メールを作成する

あなたは、HubSpot（ポータルID 8170895）の画面を操作して、Webサイトの新しい資料DLページで使うフォームと、資料を届けるお礼メールを用意します。既存の資料と同じ作りにそろえることが目的です。新しい設定を考える必要はありません。

## 前提

| 項目 | 内容 |
|---|---|
| 資料名 | {{資料名}} |
| 資料のファイル（HubSpotのファイルマネージャーにアップロード済み） | {{ファイルURL}} |
| 掲載するページ（公開前） | https://eitoss.com/document/{{slug}}/ |
| 複製元のフォーム | {{複製元フォーム名}}（フォームID `{{複製元フォームID}}`） |
| 複製元のお礼メール | {{複製元お礼メール名}} |

## 守ること

- 既存のフォームやメールは**編集しない**。必ず「複製」してから、複製したものを編集する。
- お礼メールの公開、ワークフローのオンなど、**実際に送信が始まる操作の直前には、画面の内容を要約してユーザーに確認を取る**。
- 画面の表示や項目名が下の説明と違うときは、推測で進めず、ユーザーに確認する。
- 終わったら、最後の「報告」の形式でユーザーに報告する。

## STEP 1：フォームを作る

1. マーケティング → フォーム を開き、フォームID `{{複製元フォームID}}` のフォーム（{{複製元フォーム名}}）を探す。
2. そのフォームの「アクション」から「複製」する。
3. 複製したフォームを次のとおり設定する。

| 項目 | 設定 |
|---|---|
| フォーム名 | {{フォーム名}} |
| 入力項目 | 複製元のまま |
| 送信後の動作 | 複製元と同じ（別のページへ移動：https://eitoss.com/document/thanks/ ）。複製元の設定が違っていたら、その内容をユーザーに伝えて、どちらにするか確認する |
| 送信の通知先 | 複製元のまま |

4. フォームを公開（保存）し、**フォームID** を控える。フォームIDは、編集画面のURLの末尾、または「共有」→「埋め込みコード」の `formId:` の値。

## STEP 2：お礼メールを作る

1. マーケティング → Eメール を開き、「{{複製元お礼メール名}}」を「複製」する。
2. 複製したメールを次のとおり編集する。

| 項目 | 設定 |
|---|---|
| メール名（社内用） | {{お礼メール名}} |
| 件名 | {{件名}} |
| プレビューテキスト | {{プレビューテキスト}} |
| 本文の資料名 | 複製元の資料名が書かれている箇所を「{{資料名}}」に置き換える |
| ダウンロードボタンのリンク先 | {{ファイルURL}} |
| それ以外の文面・デザイン | 複製元のまま |

3. プレビューを開き、件名、資料名、ボタンのリンク先が正しいことを確認する。
4. ユーザーに確認を取ってから、メールを公開する。

## STEP 3：フォーム送信でお礼メールが届くようにする

1. 複製元のお礼メール（{{複製元お礼メール名}}）が、どの仕組みで送られているかを確認する（ワークフロー、またはフォームの自動フォローアップメール）。
   - ワークフローの場合は、自動化 → ワークフロー で、複製元フォームの送信をきっかけにしているワークフローを探す。
2. 同じ仕組みで、STEP 1 のフォームが送信されたら STEP 2 のお礼メールが送られるように設定する。
   - ワークフローの場合：既存のワークフローを「複製」し、名前を「{{ワークフロー名}}」にして、きっかけのフォームと送信するメールだけを差し替える。再登録の設定は複製元のまま。
3. ユーザーに確認を取ってから、ワークフローをオンにする（またはフォローアップメールを有効にする）。

## STEP 4：テスト送信

1. ユーザーに、テストに使うメールアドレスを確認する。
2. フォームのプレビュー（またはテスト用のページ）から、そのアドレスで送信する。
3. 次を確認する。
   - お礼メールが届き、件名と資料名が正しい
   - ダウンロードボタンから資料を開ける
   - コンタクトにフォーム送信の履歴が残っている
   - 送信の通知が届いている

## 報告

次の形式で、ユーザーに報告する。

```
フォームID：（STEP 1 で控えたID）
フォーム名：{{フォーム名}}
お礼メール：{{お礼メール名}}（公開済み／未公開）
自動送信：（ワークフロー名、またはフォローアップメール）（オン／オフ）
テスト：（届いた／届かない、ダウンロードできた／できない）
気になった点：（あれば）
```
