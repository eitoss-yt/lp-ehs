# 指示書：「PPWR適合宣言書 作成ガイド」資料DLフォームの作成（HubSpot）

担当：admin | HubSpot clone（または HubSpot の管理者）
依頼元：admin | Web/LP
関連PR：https://github.com/eitoss-yt/lp-ehs/pull/132

## 1. 目的と完成の条件

新しい資料DLページ https://eitoss.com/document/ppwr-declaration-of-conformity/ （PR #132 で作成済み、未公開）に埋め込むフォームと、送信者に資料を届けるお礼メールを用意する。

次の3つがそろったら完了。

- [ ] フォームを作成し、フォームIDを Web/LP スレッドに伝えた
- [ ] お礼メールを作成し、フォーム送信時に自動で届くようにした
- [ ] テスト送信で、お礼メールが届き、2つのファイルをダウンロードできることを確認した

フォームIDを受け取ったら、Web/LP スレッドがLPに設定し、PR #132 をマージして公開する。

## 2. 配布する資料

| 資料 | 形式 | ファイル（PR #132 のブランチ） |
|---|---|---|
| PPWR適合宣言書 作成ガイド（18ページ） | PDF | https://github.com/eitoss-yt/lp-ehs/blob/claude/ppwr-doc-guide-lp/assets/dl/PPWR_DoC_guide_eitoss.pdf |
| PPWR適合宣言書 テンプレート（3ページ） | Word | https://github.com/eitoss-yt/lp-ehs/blob/claude/ppwr-doc-guide-lp/assets/dl/PPWR_DoC_template_eitoss.docx |

## 3. 手順

### STEP 1：ファイルを HubSpot のファイルマネージャーに置く

既存のお礼メール（「お礼メール_資料送付_PPWR」）は、ファイルマネージャーの `DL` フォルダに置いたPDFにリンクしている。同じ形にそろえる。

1. 上の2ファイルをダウンロードする（GitHubの各ページ右上の「Download raw file」）
2. HubSpot：マーケティング → ファイル → `DL` フォルダに2ファイルをアップロードする
   - ファイル名はそのまま（`PPWR_DoC_guide_eitoss.pdf`、`PPWR_DoC_template_eitoss.docx`）
   - 公開設定は「公開」（検索エンジンにはインデックスさせない設定を選ぶ）
3. それぞれの「URLをコピー」で公開URLを控える（STEP 3で使う）

> PR #132 をマージすると、同じファイルが https://eitoss.com/assets/dl/PPWR_DoC_guide_eitoss.pdf と https://eitoss.com/assets/dl/PPWR_DoC_template_eitoss.docx でも公開される。お礼メールはHubSpotのファイルURLを使い、既存の資料と運用をそろえる。

### STEP 2：フォームを作成する

既存の「EU PPWR 対応 要点まとめ」用フォーム（フォームID `83a73b1f-76df-4e38-b2b6-b19bd37bc567`）を複製して作る。

1. HubSpot：マーケティング → フォーム → 上記フォームの「アクション」→「複製」
2. 設定を次のとおり変更する

| 項目 | 設定 |
|---|---|
| フォーム名 | 資料DL_PPWR適合宣言書作成ガイド |
| 入力項目 | 複製元のまま（会社名、部署名、氏名、メールアドレス、電話番号など） |
| 送信ボタンの文言 | 複製元のまま |
| 送信後の動作 | 複製元と同じ（別のページへ移動：https://eitoss.com/document/thanks/ ） |
| 通知の送信先 | 複製元のまま（営業担当への送信通知） |

送信後は、既存の資料と同じくサンクスページ（面談予約のカレンダー付き）へ移動させる。LPには、フォーム送信時にページ上へダウンロードボタンを出す処理も入れているが、サンクスページへ移動する場合は表示されない。資料はお礼メールで届くため問題ない。

#### 任意：入力項目「PPWR上の自社の立場」を追加する

営業が優先度を判断する材料として、次の項目の追加をおすすめする（任意回答）。追加する場合は、先にコンタクトのプロパティを作る。

| 項目 | 設定 |
|---|---|
| プロパティ名（表示） | PPWR上の自社の立場 |
| 種類 | ドロップダウン選択 |
| 選択肢 | 製造業者（自社ブランドでEUへ出荷）／サプライヤー（包装材・部材の供給、OEM）／わからない |
| 必須 | いいえ |

「製造業者」または「わからない」を選んだ送信者は相談につながりやすいため、通知メールの件名や営業への割り当てで目立つようにしておくとよい。

### STEP 3：お礼メールを作成する

既存の「お礼メール_資料送付_PPWR」（自動メール）を複製して作る。

1. HubSpot：マーケティング → Eメール → 「お礼メール_資料送付_PPWR」→「複製」
2. 次のとおり変更する

| 項目 | 設定 |
|---|---|
| メール名（社内用） | お礼メール_資料送付_PPWR適合宣言書 |
| 件名 | 【資料送付】「PPWR適合宣言書 作成ガイド」資料（エイトス） |
| プレビューテキスト | 作成ガイド（PDF）とWordテンプレートをお送りします。 |
| ダウンロードボタン | 2つにする（下の本文案を参照）。リンク先はSTEP 1で控えたURL |

本文案（複製元の文面に合わせ、差し替える部分だけ記載）

```
この度は、資料ダウンロードありがとうございます！
下記より、資料をご覧いただけます。ご確認くださいませ。

[ボタン] 作成ガイド（PDF）のダウンロードはこちら →
[ボタン] テンプレート（Word）のダウンロードはこちら →

テンプレートの1ページ目が宣言書の様式、2ページ目以降が記入の手引きです。
記入の手引きのページは、発行・提出前に削除してご利用ください。

自社が製造業者に当たるかの判定や、宣言書の記載内容のレビューなど、
PPWR対応のご相談も承っております。
https://eitoss.com/cayzen/ehsresearch/#cta
```

3. プレビューで、2つのボタンのリンク先が正しいことを確認して公開する

### STEP 4：フォーム送信でお礼メールが届くようにする

既存の「お礼メール_資料送付_PPWR」と同じ方法で設定する（フォームの自動フォローアップメール、またはワークフロー）。

ワークフローの場合の設定例：

| 項目 | 設定 |
|---|---|
| 登録のきっかけ | フォーム「資料DL_PPWR適合宣言書作成ガイド」が送信された |
| 再登録 | オン（同じ人が別の機会に再度申し込んでも届くように） |
| アクション | Eメール「お礼メール_資料送付_PPWR適合宣言書」を送信 |

### STEP 5：フォームIDを確認して伝える

フォームIDは、フォームの編集画面のURL末尾、または「共有」→「埋め込みコード」の `formId:` の値。

確認したら、Web/LP スレッドに次を伝える。

- フォームID
- お礼メールと自動送信の設定が完了したこと

LP側の差し替え箇所（Web/LP スレッドが対応）：`document/ppwr-declaration-of-conformity/index.html` の `var DOC_FORM_ID = "REPLACE_WITH_HUBSPOT_FORM_ID";`

## 4. テスト

PR #132 のプレビュー（https://lp-ehs-git-claude-ppwr-doc-guide-lp-eitoss-yts-projects.vercel.app/document/ppwr-declaration-of-conformity/ ）でフォームIDを差し替えた後に確認する。

- [ ] フォームが表示され、社内のメールアドレスで送信できる
- [ ] 送信後、サンクスページ（https://eitoss.com/document/thanks/ ）に移動する
- [ ] お礼メールが届き、件名・宛名・2つのボタンのリンク先が正しい
- [ ] HubSpotにコンタクトが作成され、フォーム送信の履歴が残っている
- [ ] 営業への通知メールが届く
- [ ] GA4のリアルタイムで `document_request` イベントが記録される

テストで作成したコンタクトは、確認後に削除するか、テスト用のリストに入れて配信対象から外す。
